# Grome Dashboard Project

## Что это
Аналитический дашборд для барбершопа Grome. Node.js сервер + vanilla JS фронтенд.

## Структура
- `server.js` — Express сервер, API endpoints
- `mainscript.js` — основная логика фронтенда (OVN, штрафы, опоздания, статистика)
- `index.html` — главная страница дашборда
- `handbook.json` — справочник штрафов (centralised penalty config)

## Сервер
- Работает на порту 3000
- Данные хранятся в JSON файлах
- Деплой на сервер через SSH

## Ключевые модули
- **OVN** — видеонаблюдение, проверки менеджеров
- **Опоздания (Lates)** — журнал опозданий сотрудников
- **Штрафы** — ручные и автоматические, берутся из handbook.json
- **Аналитика** — статистика по менеджерам, графики
- **Telegram бот** — уведомления менеджерам и партнёрам

## Стек
Node.js, Express, vanilla JS, Chart.js, Telegram Bot API

## Запуск
```bash
node server.js
```
